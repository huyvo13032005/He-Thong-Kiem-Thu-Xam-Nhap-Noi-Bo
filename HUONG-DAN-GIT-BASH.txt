BO SUNG DOCKER VAO PROJECT PHASE 2 HIEN TAI

1. Sao luu thu muc D:\PTTKHTTT\pentest-mgmt truoc khi chep de.
2. Giai nen BO-SUNG-DOCKER.zip vao thu muc tam.
3. Copy TOAN BO noi dung vua giai nen vao D:\PTTKHTTT\pentest-mgmt.
   Chon Replace neu Windows hoi. Cac file PHP/SQL duoc sua de chay voi Docker.
   File compose.yaml phai nam cung cap voi thu muc app, config, public.
   Neu ban da tu sua code sau Phase 2, so sanh file truoc khi chep de.
4. Mo Docker Desktop va cho Engine chay (Linux containers).
5. Mo Git Bash, chay tung lenh:

cd /d/PTTKHTTT/pentest-mgmt
ls -l Dockerfile compose.yaml scripts/setup.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "./scripts/setup.ps1"
docker compose up -d --build
docker compose ps -a
